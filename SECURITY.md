# Security Policy

## Supported versions

This site is deployed continuously from the `main` branch.

| Version | Supported |
| --- | --- |
| `main` | ✅ |

## Reporting a vulnerability

Please report security issues responsibly:

1. **Preferred:** use GitHub's *private vulnerability reporting* — go to the **Security** tab of this repository and click **Report a vulnerability**. This keeps the report private until a fix is ready.
2. Alternatively, contact the repository owner directly.

Please include:

- A description of the issue and its impact
- Steps to reproduce or a proof of concept
- Any relevant logs or screenshots

## Scope

This repository contains the public catalog website for Aaron Enterprises. Reports about the demo storefront (client-side only, no backend) are welcome; out-of-scope reports include social-engineering and denial-of-service.
